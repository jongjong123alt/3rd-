분석 전 확인

실제 분석에는 Gemini API 키 설정이 필요합니다. 분석 결과는 원문과 대조한 뒤 저장해 주세요.

분석할 자료를 입력하는 곳입니다. 요약 줄 수나 정리 방식은 아래 추가 요구사항에 적어 주세요.

PDF·PNG·JPG, 최대 5MB. 텍스트 또는 파일 중 하나는 필수입니다. 입력 내용과 파일은 Gemini API로 전송되며, 분석용 원본 파일은 이 앱에 저장하지 않습니다. 개인정보나 API 키를 포함하지 마세요.

공지 원문·첨부파일에 적용할 분석 요청입니다. 요약은 최대 2,000자이며, 원문 없이 요구사항만 입력하면 분석할 수 없습니다. 분석 오류 후 파일은 다시 첨부해 주세요.

어떤 요구사항을 적을 수 있나요?
  • 분량: “핵심만 5줄로”, “500자 이내로 자세히”
  • 표현: “초보자도 이해하게”, “영어로 요약해 줘”
  • 형식: “번호 목록으로”, “항목과 조건을 텍스트 표로”
  • 중점: “제출 조건과 평가 기준 중심으로”, “필수와 선택을 구분해 줘”
  • 작업: “할 일을 작은 단계로”, “제출 전 검토할 항목을 정리해 줘”
  • 확인: “파일과 텍스트의 다른 조건을 알려줘”, “빠진 정보를 표시해 줘”

원문에 없는 정보는 확인이 필요합니다. 요약은 2,000자, 제출물·할 일은 각각 30개 이내입니다. 웹 검색·실제 파일 생성·자동 제출은 이 분석 화면에서 지원하지 않습니다. 조건이 충돌하면 분량이나 요청을 조정해 주세요.
