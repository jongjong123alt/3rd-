백업 다운로드

DB의 내 과제 기록은 data.json으로, 첨부파일은 별도 파일로 포함됩니다. 다른 계정의 기록, 로그인 비밀번호, API 키는 포함하지 않습니다. ZIP 최대 50MB, 압축 전 합계 100MB, 기록 JSON 2MB, 표별 최대 5,000개 항목을 지원합니다.

백업에서 복원

과제 노트에서 만든 ZIP을 선택하세요. 현재 로그인한 계정에 새 과제로 추가하며 기존 데이터는 삭제하지 않습니다. 같은 백업을 여러 번 복원하면 항목이 중복됩니다. 새 PC에서는 먼저 계정을 만든 후 로그인해 복원하세요.
