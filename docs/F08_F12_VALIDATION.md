# F-08~F-12 로컬 검증 가이드

## 업데이트
1. 앱 종료 후 SQLite 파일 `instance/assignments.db`를 별도 위치에 복사해 백업합니다.
2. `git pull origin main`
3. `python -m unittest discover -s tests -v`
4. `python app.py`
5. 브라우저에서 Ctrl+Shift+R로 새로고침합니다.

## 검증
- F-08: 오늘/3일 후/지난 마감일 과제에서 D-DAY, D-3, D+N 확인. 완료 과제는 카운트다운 숨김.
- F-09: 과제 등록/수정에서 우선순위 선택, 대시보드에서 필터/정렬, 기존 과제는 '보통' 유지 확인.
- F-10: 왼쪽 메뉴에서 JSON 전체 백업 및 CSV 내보내기 확인. JSON에 과제/체크리스트/메모가 포함되는지 확인. CSV에는 과제 목록만 포함.
- F-11: 과제 상세 화면에서 메모/진행 기록 작성, 수정, 삭제 및 과제 삭제 시 연관 기록 삭제 확인.
- F-12: 대시보드에서 상태 분포, 과목별 상위 5개, 체크리스트 완료율 확인. 검색 필터를 바꾸어도 통계는 전체 과제 기준인지 확인.

## 안전 및 한계
- 기존 SQLite DB는 삭제하거나 초기화하지 않습니다. priority 컬럼과 assignment_notes 테이블을 추가하는 마이그레이션만 수행합니다.
- CSV 및 JSON은 **다운로드 기능만** 제공하며, 백업 파일 업로드·복원 기능은 없습니다.
- 인증/계정 분리가 없는 로컬 단일 사용자 프로토타입입니다. 전체 데이터 내보내기 URL이 있으므로 **인터넷에 공개 배포하지 마세요**.
- API 키를 담은 `.env` 파일은 백업에 포함되지 않습니다.
- 위 기능들은 코드를 구현한 상태이며 로컬 자동 테스트와 브라우저 검증은 실행 결과를 확인한 뒤 완료로 표시합니다.
