# 일상 과제 관리를 위한 여섯 기능

## 1. 오늘 할 일 직접 지정

과제 상세의 미완료 체크리스트에서 **오늘 할 일에 추가**를 누릅니다. 먼 마감일이나 기한 없는 과제도 직접 선택할 수 있고, 지정은 DB에 저장됩니다. 대시보드에서 체크 버튼으로 완료할 수 있습니다. 첫 네 작업 이후에는 나머지 작업을 펼쳐 봅니다.

직접 지정은 해당 날짜에만 표시합니다. 오늘이 마감인 과제의 미완료 체크리스트와 오늘 학습 계획은 자동 표시됩니다. 기한 없는 작업은 이제 직접 지정해야 오늘 할 일에 나옵니다. **직접 지정 해제**는 수동 지정을 해제하며, 오늘 마감인 작업은 자동 표시가 유지됩니다. 완료 과제와 완료 체크리스트는 오늘 할 일에서 제외됩니다.

## 2. 목록에서 상태 변경

과제 관리의 각 행에서 상태를 선택하고 **변경**을 누릅니다. 로그인 계정 소유의 과제만 변경하며 CSRF 검증을 유지합니다. 현재 보기와 검색 조건은 내부 목록 주소로 돌아갈 때 유지합니다. 기존 자동 재계획이 켜진 과제는 실제 상태가 바뀌었을 때 기존 정책에 따라 재계획할 수 있습니다. 완료 처리 시에는 재계획을 요청하지 않습니다.

## 3. 완료 보관함

과제 관리 기본 보기는 **진행할 과제**입니다. 완료 상태로 바꾸면 **완료 보관함**에서 확인할 수 있습니다. 완료 보관함에서 시작 전/진행 중으로 바꾸면 다시 진행 목록으로 돌아옵니다. **전체** 탭에서는 두 종류를 모두 확인합니다. 보관은 삭제가 아니며 별도 데이터 복제도 하지 않습니다.

## 4. 과목별 보기

왼쪽 메뉴에서 과목별 전체·완료 수를 확인하고, 과목을 선택하면 해당 과제만 표시합니다. 과제 관리의 과목 필터와 다른 검색 조건을 함께 사용할 수 있습니다. 과목 미지정 그룹도 지원합니다.

## 5. AI 요청 반영 점검

AI 분석 결과 화면에서 요청한 줄 수·글자 수·제출물/할 일 수를 실제 결과와 비교합니다. 이내/이하/이상 등 수량 조건도 구분합니다. 줄 수는 화면 자동 줄바꿈이 아닌 명시적 줄바꿈 기준입니다. 문장 수, 언어, 쉬운 말, 사실성 등 의미적 조건은 **직접 검토**로 표시하며 충족했다고 자동 보장하지 않습니다.

검토 결과나 요구사항을 수정하면 **수정한 내용 다시 점검**을 누를 수 있습니다. 현재 요구사항과 검토 입력을 서버에서 다시 계산하며, 이 과정은 Gemini를 호출하거나 데이터를 저장하지 않습니다. AI 결과 생성·검토 후 저장 정책은 기존과 같습니다.

## 6. 계정별 데이터·첨부파일 백업과 복원

**데이터 백업**에서 ZIP을 내려받습니다. DB의 해당 계정 과제·체크리스트·메모·일정·첨부파일 메타데이터는 `data.json`, 실제 파일은 `attachments/`에 포함됩니다. 서버의 SQLite 파일 전체나 다른 사용자/인증 정보, `.env` 설정을 복사하지 않습니다.

새 PC에서도 프로젝트를 실행하고 계정을 만든 뒤 로그인해 ZIP을 복원할 수 있습니다. 복원은 현재 계정에 새 ID로 **추가**하며 기존 항목을 삭제하거나 덮어쓰지 않습니다. 같은 ZIP을 반복 복원하면 중복 항목이 생긴다는 동의가 필요합니다. 작성일과 수동 일정 구분도 보존합니다.

- ZIP 50MB 이하, 압축 해제 크기 합계 100MB 이하.
- 데이터 JSON 2MB 이하, 표별 5,000개 항목 이하, 첨부파일당 5MB 이하.
- 누락된 첨부파일이 있으면 완전한 백업인 것처럼 제공하지 않고 안내합니다.
- 지원 버전·ID 연결·필드 길이·날짜·상태·압축 크기·파일명을 검증합니다.
- 임의 경로로 ZIP을 해제하지 않습니다. 복원 파일은 새 임의 이름으로 저장합니다.
- 복원 DB 작업은 한 트랜잭션으로 처리합니다. 실패하면 새 파일도 정리합니다.
- 이전에 제거했던 `/export/*`와 `/backup/restore` 경로는 그대로 제거 상태입니다. 새 ZIP 복원은 `/backup/import`를 사용합니다.

## 개발·검증

기존 DB는 앱 시작 시 체크리스트의 `focus_date` 열만 자동 추가합니다. 기존 기록과 계정은 보존됩니다. 앱 요청 크기 상한은 백업 업로드를 위해 64MB로 늘렸으나, 기존 과제 첨부 및 AI 분석 파일은 각각 기존 5MB 제한을 유지합니다.

```bash
.venv/bin/python -m unittest discover -s tests -v
```

현재 98개 테스트 통과. 소유권·CSRF, 지정/해제, 완료 보관/복귀, 과목 필터, 측정 가능한 요청 검사, 계정별 ZIP 내용, 사용자 간 복원 ID 재배정, 손상 ZIP·경로 조작 거부, 실패 시 트랜잭션 보존을 확인했습니다.

브라우저 반복 검사:

```bash
# 별도 터미널에서 테스트 전용 임시 DB 서버
.venv/bin/python tests/ui_server.py
# 기존 브라우저 도구 설치 방법은 docs/design/VALIDATION.md 참고
NODE_PATH="/tmp/campus-ui-tools/node_modules:${NODE_PATH:-}" node tests/ui_smoke.cjs
NODE_PATH="/tmp/campus-ui-tools/node_modules:${NODE_PATH:-}" node tests/ui_productivity.cjs
```

48개 페이지/뷰포트 검사에서 자동 접근성 위반·가로 넘침·이미지 누락·브라우저 오류가 없었습니다. 새 기능의 실제 브라우저 조작과 ZIP 다운로드·추가 복원이 통과했습니다. AI 점검 화면은 모의 생성 응답과 실제 점검 엔드포인트로 검증했으며, 실제 Gemini 응답 품질은 API 키가 없어 미검증입니다. 자동 접근성 검사는 전체 준수를 보장하지 않습니다.
