# F-19~F-21 구현 및 검증

## F-19: PDF·이미지 과제 공지 분석
- **AI 공지 분석** 화면에서 PDF/PNG/JPG 파일(5MB 이하)과 텍스트 과제 요구사항(최대 10,000자)을 동시에 입력하면 Gemini 멀티모달 API로 **한 번에** 분석합니다. 둘 중 하나만 입력해도 됩니다.
- 원본 파일은 앱에 저장하지 않습니다. Gemini API로 전송되므로 개인 정보·비밀 정보가 담긴 공지는 업로드하지 마세요.
- 반환값은 기존 F-04와 동일한 과제명·과목·제출기한·요약·제출물·할 일 구조입니다.
- 반드시 **분석 결과를 검토·수정한 후** 기존 F-05 버튼으로 저장합니다.
- 형식과 파일 시그니처를 검사하지만, PDF 내부 내용 전체의 안전성을 보증하지는 않습니다.
- 실제 Gemini 호출과 스캔 품질은 사용자의 환경에서 직접 확인해야 합니다.

## F-20: 브라우저 마감 알림
- 대시보드의 **브라우저 알림 켜기** 버튼으로 사용자 동의를 받습니다.
- 동의하면 대시보드 접속 시 마감 예정(3일 이내) 및 기한이 지난 미완료 과제를 알립니다.
- 브라우저 localStorage로 계정별·과제별·날짜별 중복 알림을 제한합니다.
- **브라우저가 닫혀 있으면 알림을 보내지 않습니다.** 백그라운드 푸시나 예약 알림은 구현하지 않았습니다.
- localhost 또는 HTTPS 환경에서 지원하는 브라우저의 알림 권한이 필요합니다.
- 알림은 개인별 브라우저에 저장되므로 다른 브라우저/PC와 설정이 동기화되지 않습니다.

## F-21: 선택형 AI 자동 재계획
- 과제 상세의 **AI 자동 재계획 켜기**를 눌러 명시적으로 활성화합니다. 기본값은 꺼짐입니다.
- 활성화 후 과제명·설명·제출기한·우선순위 또는 체크리스트를 변경하면 Gemini가 새 계획을 생성합니다.
- 기존 AI 생성 항목만 교체하고, 사용자가 직접 수정한 항목은 보존합니다.
- API 오류가 나면 기존 계획을 유지하고 **AI 재계획 다시 시도** 버튼을 표시합니다.
- API 호출은 해당 저장 요청 중 실행되어 화면 이동까지 기다릴 수 있습니다.
- 완료된 과제·마감일 없는 과제·마감 지난 과제는 자동 생성할 수 없습니다.
- 기존 **Gemini 일정 생성/다시 생성** 버튼(F-14)은 수동으로 전체 일정을 교체하는 동작입니다.
- 기존 자동 재계획 기능은 유지됩니다. JSON 백업 내보내기/복원 기능은 사용자 요청으로 제거했습니다.

## PC에서 확인
1. `instance/assignments.db`와 `instance/uploads` 폴더를 백업합니다.
2. `git pull origin main`
3. `python -m pip install -r requirements.txt`
4. `python -m unittest discover -s tests -v`
5. `python app.py` 실행 후 로그인합니다.
6. F-19: PDF·PNG·JPG 공지를 분석하고, 미리보기 수정 후 저장합니다.
7. F-20: 대시보드에서 알림 권한 허용, 하루 중복 여부, 알림 끄기를 확인합니다.
8. F-21: 과제 상세에서 자동 재계획을 켠 뒤 체크리스트/기한을 변경하고, 수동 편집 보존과 실패 후 재시도를 확인합니다.

GitHub Actions 단위 테스트는 Gemini 응답을 모의 처리하며 실제 API·브라우저 권한·Windows 환경을 검증하지 않습니다.
