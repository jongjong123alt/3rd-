# 설계 자료 검증 기록

검증일: 2026-11-24. 애플리케이션 기준: `537e49f`.

- 기존 기능 테스트: `.venv/bin/python -m unittest discover -s tests -q` → **98개 통과**. 기본 Python에는 Flask가 없어 첫 실행은 수집에 실패했으며, 프로젝트 가상환경에서 정상 재실행했다.
- 소스 변경 범위: 문서·설계 산출물만 변경. 백엔드·DB 스키마·로그인 정책·템플릿·CSS 변경 없음.
- 구현 목록: 격리된 빈 SQLite DB의 PRAGMA와 Flask URL 맵에서 6개 테이블, 40개 경로 규칙 확인. 실제 사용자 기록은 자료에 포함하지 않음.
- draw.io 원본: 비압축 mxfile XML 7페이지. 페이지별 ID 중복 없음, 연결선 출발·도착 ID 유효, 모든 도형이 페이지 영역 안에 있음.
- 렌더링: mxGraph 4.2.2의 페이지별 XML 디코딩으로 PNG·SVG 생성. Chromium에서 한글·도형·분기선 열람 확인. 텍스트 도형의 기본 배경과 학습 계획 도형 겹침을 수정함.
- PDF: 동일 렌더링에서 생성, 7페이지 및 각 페이지의 추출 가능한 텍스트 확인.
- draw.io 데스크톱 앱 자체에서 열기 시험은 수행하지 않음. 표준 mxfile/mxGraphModel 구조를 사용하고 호환 렌더러로 디코딩 확인함.
- 외부 Gemini 실호출과 이번 문서 작업의 새 브라우저 기능 회귀 테스트는 수행하지 않음. 테스트의 AI 응답은 모의 응답이며, 과거 UI 검증 기록과 이번 검증을 구분함.

`generate_design.py`는 원본 XML만 재생성한다. PDF·PNG·SVG를 변경하려면 수정된 XML을 다시 렌더링해야 한다.
