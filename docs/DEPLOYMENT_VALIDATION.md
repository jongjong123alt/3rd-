# 배포 준비 검증 — 2026-11-24

- `.venv/bin/python -m unittest discover -s tests -q`: 기존 98개 + 운영 설정 테스트 2개 = **100개 통과**.
- 새 테스트는 별도 프로세스·임시 저장 폴더를 사용한다. 운영 시크릿 누락 시 시작 거부, 지정 데이터 경로, Secure 쿠키, 로컬 주소에서도 운영 웹 회원가입 차단, CLI 계정 생성·해시 저장·중복 거부, 앱 재생성 후 계정 유지 확인.
- 실제 Gunicorn을 임시 데이터 경로·운영 모드로 실행하여 `/health` HTTP 200 확인 후 종료.
- 기존 프로젝트 DB·첨부파일을 이전하거나 삭제하지 않음. 로컬 기본 경로 유지.
- Render 설정은 저장소의 Blueprint 선언이다. 플랫폼 배포·과금·HTTPS·영구 디스크의 실제 재시작 보존·실제 Gemini 호출은 아직 검증하지 않음.
- 웹 가입 차단과 서버 CLI 계정 준비 절차를 추가했다. 실제 발표용 계정이나 비밀번호는 생성하지 않음.
