# AI 기능 설명 — 과제 노트

최신 정리: 2026-11-24. 제출용 설명이며 실제 Gemini 호출 성공 기록과 구분한다.

## 어떤 기능인가?

교수님의 과제 공지 텍스트 또는 PDF·PNG·JPG에서 과제명, 과목, 제출기한, 핵심 요약, 필수 제출물, 수행할 일을 추출한다. 사용자는 추가 요구사항을 함께 전달할 수 있으며, 분석 결과를 검토·수정한 후 저장하면 과제와 체크리스트가 생성된다. 분석만으로 개인 과제가 자동 저장되지는 않는다.

과제 상세에서는 마감과 할 일을 바탕으로 학습 계획을 생성한다. 자동 재계획을 켠 과제는 관련 변경 시 다시 계획하며, 직접 수정한 일정은 보존한다. 수동으로 계획 전체를 다시 생성하는 기능은 기존 계획 전체를 교체하므로 구분해서 사용한다.

## 왜 AI가 필요한가?

과제 공지는 문장 구조와 표현이 매번 다르다. 자연어 공지에서 여러 제출물과 작업을 구분하고 실행 가능한 할 일로 정리하는 데 AI를 사용한다. 단순한 날짜 정렬, 과제 저장, 체크리스트 완료, 달력 표시는 일반 프로그램으로 처리한다.

## 구현 방식과 한계

- 서버에서 `google-genai` SDK로 Gemini API를 호출한다. 기본 모델은 `gemini-2.5-flash`이며 환경변수로 변경할 수 있다.
- API 키는 서버 환경변수로 설정한다. 브라우저 코드와 저장소에는 키를 넣지 않는다.
- 공지와 추가 요구사항을 구조화된 JSON 출력 지침과 함께 전달하고 응답 형식·날짜·문자 길이를 검사한다.
- 파일이 있으면 텍스트와 함께 분석한다. 분석 원본 파일은 앱에 저장하지 않지만 입력 자료는 외부 Gemini API로 전송된다.
- 요청 점검은 줄 수·글자 수·항목 수 등의 로컬 계산이다. 의미적 요구사항의 완전한 이행을 보장하지 않으며 원문 대조가 필요하다.
- API 오류·네트워크 실패·잘못된 응답은 오류로 안내한다. 실패 결과를 성공으로 표시하지 않는다.
- 무료 쿼터와 실제 API 성공 여부는 별도 확인이 필요하다. 자동 테스트의 모의 응답 통과가 실호출 성공을 의미하지 않는다.

## 제출용 짧은 설명

> 과제 노트는 Gemini를 이용해 비정형 과제 공지에서 제출기한·제출물·수행할 일을 추출하고 학습 계획을 제안하는 대학 과제 관리 서비스입니다. 공지마다 문장과 형식이 달라 자연어 해석에 AI가 필요합니다. 분석 결과는 사용자가 원문과 비교하고 수정한 뒤 저장하며, 과제 관리·달력·체크리스트는 일반 프로그램으로 처리합니다.
