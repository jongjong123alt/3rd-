# 배포 현황과 준비

2026-11-24 사용자 확인: **미배포**. 실제 서비스 URL은 아직 없다.

현재 운영 서버·영구 저장소·WSGI 구성이 완비되지 않았으므로 배포가 완료된 것으로 표시하지 않는다. `google-genai`는 현재 의존성에 포함되어 있으나 `gunicorn`은 포함되어 있지 않다.

배포 전 조건과 발표 전 점검은 [데모데이 체크리스트](DEMO_DAY_CHECKLIST.md)에 정리했다. 현재 구조·로그인 정책·데이터 저장 경계는 [아키텍처 문서](ARCHITECTURE.md)를 참고한다.

플랫폼을 선택한 뒤 운영 실행 명령, 영구 SQLite·첨부파일 경로, 환경변수, 로컬 전용 회원가입에 따른 계정 준비 방법을 구체화하고 실제 URL에서 검증해야 한다. 임의의 URL이나 배포 성공 기록은 작성하지 않는다.
