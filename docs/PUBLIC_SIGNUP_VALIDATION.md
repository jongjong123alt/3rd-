# 배포 환경 회원가입 변경 · 2026-11-24

## 변경 내용

- 배포 사이트에서도 `/auth/register` GET·POST를 허용한다. 별도 Render 환경변수 추가 없이 최신 코드 배포로 적용된다.
- 로그인 화면의 새 계정 만들기와 공개 소개의 로컬 전용 안내를 현재 동작에 맞췄다.
- 아이디 형식·길이, 비밀번호 길이, 해시 저장, CSRF, 중복 아이디 처리와 세션 갱신을 유지한다.
- 운영 환경의 공개 가입은 첫 가입자라도 소유자 없는 기존 과제를 자동 귀속하지 않는다. 다른 계정의 과제·상세 접근 제한을 유지한다.
- 로컬 개발의 첫 로컬 가입은 기존 데이터 이전 동작을 유지한다. CLI의 확인 후 이전 기능도 유지한다.

## 검증

- `.venv/bin/python -m unittest discover -s tests -q`: **104개 통과**.
- 신규 회귀 검증: 공개 원격 가입, 가입 후 로그인 상태, 중복 아이디·잘못된 아이디·짧은 비밀번호·CSRF 누락 거부, 해시 저장, 다른 계정 과제 차단, 로그아웃 후 재로그인.
- 운영 환경을 별도 프로세스·임시 DB로 실행해 Secure 쿠키 설정과 실제 원격 주소의 공개 가입, 소유자 없는 기존 과제 미귀속 확인.
- Gunicorn 운영 모드를 임시 DB로 실행하고 Chromium에서 로그인 화면 → 새 계정 만들기 → 가입 → 자동 로그인·대시보드 이동 확인. 390px 화면 회원가입 폼 가로 넘침 없음. localhost는 브라우저가 신뢰하는 개발 주소이며 실제 배포 HTTPS 시험과 구분한다.
- 실제 Render 서버에 테스트 계정이나 데이터를 작성하지 않았다. 최신 커밋의 배포 완료 후 실제 사이트에서 최종 가입 확인이 필요하다.

## 무료 플랜의 남은 제약

공개 가입이 가능해져도 임시 SQLite·첨부파일의 영구 저장 문제는 해결되지 않는다. 재시작·재배포 시 계정과 데이터가 사라질 수 있다. 데이터 보존에는 영구 저장소 또는 외부 DB·파일 저장소가 필요하다.

기존 아키텍처·화면·draw.io 문서는 각 문서의 기준 커밋을 기록한 당시 설계다. 로컬 전용 회원가입을 설명한 부분보다 이 변경 기록과 최신 배포 안내를 우선한다.
