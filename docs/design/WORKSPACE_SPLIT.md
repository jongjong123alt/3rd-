# 대시보드와 과제 관리 분리

## 화면 역할

- `/`: 비로그인 시 기존 소개 화면. 로그인 시 오늘 할 일, 먼저 확인할 마감 최대 4개, 전체/진행 중/기한 지난 미완료 수, 체크리스트 진행률을 표시합니다. 통계 상세와 알림 설정은 접어둡니다.
- `/assignments`: 로그인 후 전체 과제 검색·상태/우선순위/기한 필터·정렬과 체크리스트 진행률을 확인합니다. 달력·오늘 할 일·분석 통계는 이 화면에 중복 배치하지 않습니다.
- 과제 상세·등록·수정에서는 과제 관리 메뉴가 선택됩니다. 등록·삭제 후 관리 목록으로, 과제 상세의 돌아가기 역시 관리 목록으로 이동합니다.
- 기존 `/?q=...`, 상태/기한/정렬 링크는 해당 검색 조건을 유지한 `/assignments`로 안내합니다. 소개 화면과 로그인 리다이렉트 정책은 그대로입니다.

## 디자인

초록·아이보리 팔레트와 기존 아이콘을 유지합니다. 대시보드의 긴 제목, 미니 달력, 전체 과제 목록, 반복 버튼을 줄이고 요약에 집중합니다. 과제 관리에는 정렬된 데스크톱 열과 모바일용 여러 줄 목록을 사용하며, 긴 제목은 줄바꿈됩니다. 검색·필터는 기본 펼침 상태이며 접을 수 있습니다. 상태와 우선순위는 색상과 텍스트를 함께 표시합니다.

오늘 할 일은 기존 계획·체크리스트 조회 기준을 그대로 사용합니다. 표시 수를 제한한 경우 안내 문구와 각 과제로 이동하는 링크가 있습니다. 마감 없는 과제와 완료 과제는 요약 마감 목록에서 제외되지만 과제 관리에서 확인할 수 있습니다. 원래의 사용자별 접근 제한과 DB 구조는 변경하지 않았습니다.

## 검증

- Python 테스트 **78개 통과**: 화면 분리, 요약 4개 제한, 전체 목록, 탭 선택, 기존 검색 링크, 등록·삭제 후 이동, 두 사용자 간 데이터 격리 포함.
- 브라우저 **39개 화면**: 1440/390/320px에서 대시보드·과제 관리·검색 결과와 기존 공개/비공개 화면 검사.
- axe 자동 접근성 위반, 문서 가로 넘침, 이미지 누락, 브라우저 오류 없음. 자동 검사가 전체 접근성 준수를 보장하는 것은 아닙니다.
- 실제 폼 CRUD, 체크리스트, 파일 업로드, 메모, 검색, 로그아웃, 비로그인 접근 제한 통과. 모든 테스트 데이터는 임시 DB에만 저장했습니다.
- Gemini 실제 호출은 키가 없어 미검증이며 AI 기능 동작 변경은 없습니다.
