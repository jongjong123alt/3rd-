# 기능 소개를 사용 장면으로 바꾸기

## 참고 화면을 직접 확인한 결과

2026-11-17, 공유된 기존 목록 화면과 다음 공개 페이지를 확인했습니다.

- [Shovel](https://shovelapp.io): 큰 효과 중심 제목 뒤에 단계별 설명과 해당 제품 화면이 이어집니다. ‘무엇이 있는가’보다 ‘어떻게 준비하게 되는가’를 설명하는 방식이 유용합니다. 이번 페이지에는 단계별 이야기와 좌우 교차 배치를 적용했습니다.
- [MyStudyLife](https://mystudylife.com): 학생이 얻는 이점을 먼저 설명하고 시작 과정을 짧게 묶습니다. 이번 페이지도 학생의 상황과 결과를 제목에 담고, 다음 행동을 명확하게 연결했습니다. 별도 `/tour/` 경로는 확인 당시 WordPress 오류 화면이어서 제품 근거로 사용하지 않았습니다.
- 원래 화면: F-01~F-21의 동일한 카드는 개발 범위를 보여주지만, 처음 방문한 학생이 사용 흐름과 우선순위를 파악하기 어렵습니다. 사용자가 제공한 원래 화면을 변경 전 근거로 삼았습니다.

외부 사이트의 학교 연동, 동기화, 시간별 자동 배정, 백그라운드 알림 등은 이 프로젝트의 기능으로 가져오지 않았습니다. 외부 스크린샷은 제품 이미지로 사용하지 않습니다.

## 바뀐 흐름과 검증

1. **과제 모으기 — 정상:** 대시보드 실물 이미지와 검색·필터 활용 상황을 함께 설명합니다.
2. **하나씩 완료하기 — 정상:** 임시 DB에서 직접 등록·완료한 체크리스트 화면으로 ‘작게 나누기’를 설명합니다.
3. **마감 확인하기 — 정상:** 달력 실물 이미지, 일정 충돌 확인, 접속 시 브라우저 알림의 범위를 설명합니다.
4. **AI와 시작하기 — 정상:** 입력 → 검토 → 저장을 설명하며, 키 필요·오류 가능성·일반 기능과의 독립성을 명시합니다. 안내 화면에서 분석을 실행하는 척하지 않습니다.

앵커 바로가기 네 개와 로그인 CTA를 브라우저에서 직접 눌러 확인했습니다. 모바일에는 네 바로가기를 두 줄로 표시합니다. 수정 중 이미지 스타일이 작은 아이콘까지 확대하는 문제를 발견해 선택자를 제품 이미지로 한정했습니다.

- Python 테스트 62개 통과.
- 1440/390/320px, 36개 화면 검사와 브라우저 기능 시나리오 통과.
- 자동 접근성 검사 위반, 문서 가로 넘침, 이미지 누락, 브라우저 오류 없음.
- 키보드·접근성 자동 검사는 전체 WCAG 준수를 보증하지 않습니다. Gemini 실제 응답은 API 키가 없어 검증하지 않았습니다.
- DB·인증·기존 실제 기능은 변경하지 않았습니다.
