# 예상 요청과 분석 지침

텍스트 분석과 PDF·이미지 분석에 동일한 28개 공통 지침을 적용합니다. 아래는 예상 요청 32가지와 **의도한 처리 기준**입니다. 실제 Gemini가 모든 조건을 지키는지 검증한 결과표는 아닙니다.

| 예상 요청 | 처리 기준 |
|---|---|
| 핵심만 5줄로 요약해 줘 | 줄바꿈 기준 5줄, 중복 없이 핵심 요약 |
| 20줄로 빠짐없이 정리해 줘 | 줄바꿈 기준 20줄, 근거 부족 시 이유 안내 |
| 세 문장으로 요약해 줘 | 줄 수와 구분하여 문장 수 반영 |
| 500자 이내로 요약해 줘 | 글자 수 상한 내 압축 |
| 원문이 짧아도 20줄로 늘려 줘 | 정보를 날조하거나 반복하지 않고 부족함 안내 |
| 초보자도 이해하게 설명해 줘 | 전문용어를 짧게 풀이 |
| 중학생도 이해할 쉬운 말로 | 쉬운 단어와 짧은 문장 |
| 존댓말로 정리해 줘 | 지정 말투 적용 |
| 영어로 요약해 줘 | 요약과 작업 설명에 영어 적용, JSON 키 유지 |
| 한국어와 영어를 함께 써 줘 | 병기로 인한 분량 제한 고려 |
| 번호 목록으로 정리해 줘 | 요약에 번호 목록 |
| 체크리스트로 바꿔 줘 | tasks 문자열 배열 유지 |
| 제출 조건을 표로 정리해 줘 | 요약에 일반 텍스트 표, HTML 생성 금지 |
| 파일명과 제출 형식만 알려 줘 | 원문에서 명시한 조건 추출 |
| 평가 항목과 배점을 모아 줘 | 명시된 평가 기준·배점만 추출 |
| 필수와 선택을 구분해 줘 | 필수·권장·선택 구분 |
| 할 일을 작은 단계로 나눠 줘 | 동사 중심 작업 분해 |
| 제출 전에 검토할 항목을 추가해 줘 | 원문에 없는 준비 작업은 제안으로 구분 |
| 중요한 것부터 순서대로 | 근거 있는 순서와 제안 구분 |
| 하루씩 작업 일정을 제안해 줘 | 텍스트 제안만, 실제 달력 수정 완료 주장 금지 |
| 언제까지 제출해야 해? | 확정 가능한 제출일만, 연도·기준 불명확 시 확인 필요 |
| 파일과 텍스트의 다른 조건을 알려 줘 | 원문별 충돌과 차이 안내 |
| 흐릿한 이미지에서 확실하지 않은 숫자를 표시해 줘 | 확인할 수 없는 부분을 추측하지 않음 |
| 여러 과제를 나눠 정리해 줘 | 한 번에 한 과제 저장 정책 안내 |
| 배경 설명을 빼고 마감만 정리해 줘 | 요약 초점 조정, 명시되지 않은 날짜 날조 금지 |
| 뭐부터 해야 해? | 질문에 먼저 답하고 관련 항목 보존 |
| 한 줄로 요약하고 동시에 20줄로 써 줘 | 모순 안내와 적용 가능한 범위 설명 |
| 웹 검색해서 최신 참고문헌을 추가해 줘 | 검색을 수행한 척하거나 출처 날조 금지 |
| PDF를 만들어 이메일로 보내 줘 | 실제 파일·이메일 전송 불가 안내 |
| 보고서를 완성해서 자동 제출해 줘 | 공지 분석과 준비 작업 범위 안내 |
| 100개 할 일을 자세히 적어 줘 | 30개 한도 내 조정 필요 안내, 조용히 항목 삭제 금지 |
| 원문에 없는 조건은 확인 필요로 표시해 줘 | 누락 정보와 확인할 부분 구분 |

## 우선순위와 한계

- 사실성, 기존 JSON 구조와 저장 한도를 우선합니다. 그 안에서 명시적 분석 요청을 기본 요약 방식보다 우선합니다.
- 원문/파일 속 지시문과 사용자가 따로 입력한 분석 요청을 구분합니다.
- 여러 조건을 함께 확인하고, 충돌하거나 불가능한 요청을 수행했다고 답하지 않도록 지시합니다.
- title 120자, course 100자, summary 2,000자, 제출물·할 일은 각각 최대 30개·항목당 300자입니다.
- 이 변경은 모델 지침을 보강한 것입니다. 의미적 충족 여부를 자동 판정하거나 보정 재시도를 수행하는 엔진은 추가하지 않았습니다.

## 검증

72개 회귀 테스트 통과. 신규 요청 행렬 테스트는 32개 예시를 텍스트/파일 양쪽 64개 경로 조합에서 모의 SDK로 확인합니다. 요청 원문·공통 지침·입력 자료가 함께 전달되는지와 기존 JSON 처리 호환성을 검사합니다. 모의 결과가 실제 모델의 준수율을 증명하지는 않습니다.

브라우저에서 요청 예시 펼치기, PC·모바일 접근성, 오류 후 입력 보존을 확인했습니다. 실제 API 키가 없어 모델의 응답 품질과 준수율은 미검증입니다. 입력한 원문과 결과를 대조한 뒤 저장해야 합니다.
