## F-02 수동 테스트 (실행 후 체크)
- [ ] 새 과제 등록 후 목록 표시
- [ ] 제출기한 및 상태 수정 후 상세 화면 반영
- [ ] 삭제 확인 후 목록에서 제거
- [ ] 빈 과제명 입력 시 오류 표시
- [ ] 잘못된 날짜 입력 시 오류 표시
- [ ] 서버 재시작 후 등록 과제 유지
- [ ] 다른 ID 상세 조회 시 404
- [ ] 삭제 URL GET 요청으로는 삭제되지 않음

## AI 연동 이후 테스트
- [ ] 공지에서 과제명·기한·제출물 추출
- [ ] 기한 없는 공지는 추측하지 않음
- [ ] 모호한 연도는 확인 요청
- [ ] API 오류·쿼터 초과 처리
- [ ] AI 결과 수정 후 저장
- [ ] 체크리스트 상태 유지
- [ ] 공개 저장소에 비밀정보 없음

## F-03 체크리스트 검증 (사용자 확인 전)
- [ ] 과제 상세에서 할 일 추가 후 표시
- [ ] 완료 체크 및 완료 취소
- [ ] 내용 수정 후 반영
- [ ] 할 일 삭제 후 반영
- [ ] 다른 과제의 할 일에 접근 시 404
- [ ] 빈 값/300자 초과 값 저장 방지
- [ ] 과제 삭제 시 체크리스트도 삭제
- [ ] 서버 재시작 후 체크리스트 유지
