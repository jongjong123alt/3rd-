# AI 추가 요구사항 입력과 검증

기존에는 공지와 분석 요청을 한 입력란에 담고, 두 분석 프롬프트 모두 요약을 1~3문장으로 고정했습니다. 원문 속 명령을 따르지 않도록 하는 지침도 있어, ‘핵심 요약을 20줄로 작성’ 같은 형식 요청과 충돌했습니다.

## 사용 방법

1. 공지 원문을 붙여넣거나 PDF·PNG·JPG 파일을 첨부합니다.
2. 별도 **추가 요구사항**에 `핵심 요약을 20줄로 작성해 줘`처럼 분석 방식과 분량을 적습니다.
3. 분석한 내용을 원문과 대조하고 수정한 뒤 저장합니다.

추가 요구사항만으로는 분석할 수 없습니다. 원문에 없는 사실을 만들도록 요청하지 마세요. 요구사항과 저장할 요약은 각각 최대 2,000자입니다. 긴 요약은 이전처럼 조용히 잘라내지 않고 오류를 안내합니다. 브라우저에서 파일 선택은 오류 후 유지되지 않으므로 다시 첨부해야 합니다. 요구사항 텍스트는 오류 화면에서도 유지합니다.

## 구현과 검증

- 텍스트와 파일 분석 모두 원문과 요구사항을 별도로 전달합니다. 요청이 없으면 기존 짧은 요약이 기본값입니다.
- 요구사항이 있을 때 줄 수·언어·형식 요청을 반영하도록 프롬프트를 구성합니다. JSON 구조, 사실 추출, 수동 검토·저장 정책은 유지합니다.
- 회귀 테스트 70개 통과. 신규 테스트는 원문/요구사항 분리, 파일·텍스트 전달, 길이 제한, 오류 시 입력 보존, 요구사항 단독 제출 거부 및 20줄 모의 응답의 검토·저장까지 확인합니다.
- 실제 브라우저에서 요구사항 단독 입력 검증, API 키 미설정 오류 후 입력 유지, 390px 레이아웃, axe 접근성 검사가 통과했습니다.
- 이 클라우드에는 Gemini API 키가 없어 실제 모델이 줄 수를 따르는지는 미검증입니다. 모의 응답의 20줄 보존 테스트를 실제 모델의 정확한 줄 수 보장으로 해석하면 안 됩니다.

실제 요청 결과의 분량은 모델과 원문에 따라 달라질 수 있습니다. 20줄 요청은 저장 제한 내의 짧은 문장으로 작성하도록 지시하며, 제출 전 사용자가 결과를 확인해야 합니다.

## 다양한 요청의 공통 처리

분량·형식·언어·말투·평가 기준·작업 분해·일정 제안·자료 충돌·지원 불가 요청 등 28개 공통 지침이 추가되었습니다. [예상 요청 32가지와 처리 기준](AI_REQUEST_EXAMPLES.md)을 참고하세요. 지침은 텍스트/파일 분석 양쪽에 적용되며, 결과의 의미적 충족 여부를 자동 보증하는 기능은 아닙니다.
