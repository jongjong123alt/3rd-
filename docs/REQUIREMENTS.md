F-02는 필수 과제명, 선택 과목·기한·설명·상태를 다룬다.
AI는 비정형 자연어 이해에만 사용하고 DB 저장·조회는 일반 코드로 처리한다.
날짜 불명확 시 추측하지 않고 확인 요청. 사용자 확인 후 저장.
현재 사용자 로그인/데이터 분리 미구현. 외부 공개 배포 전 인증과 보안 강화 필요.

## F-08~F-12 구현 참고
- F-08: 미완료 과제만 D-day를 표시하며 지난 기한은 D+N으로 표기.
- F-09: 기존 SQLite DB에는 priority 컬럼을 안전하게 추가하고 기존 과제는 '보통'으로 설정.
- F-10: JSON은 과제·체크리스트·메모를 포함하는 백업 파일이며 복원 기능은 미구현. CSV는 과제 목록만 포함하며 Excel 수식 주입을 방지함.
- F-11: 과제별 메모/진행 기록을 시간순으로 저장하고 과제 삭제 시 함께 삭제.
- F-12: 진행 상태, 과목별 분포(상위 5개), 전체 체크리스트 진행률 표시.
- 인증 기능이 없으므로 현재 앱을 인터넷에 공개 배포하지 말 것. 특히 F-10 내보내기는 전체 로컬 데이터를 반환함.
