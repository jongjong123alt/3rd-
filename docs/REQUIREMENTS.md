# 요구사항 및 기능 목록
주제 승인 전 프로토타입. 실제 제출 전 교수 승인 필요.

| ID | 기능 | 기술 | 상태 |
|---|---|---|---|
| F-01 | 기본 대시보드 및 등록 건수 | Flask/SQLite | 구현 |
| F-02 | 과제 등록·조회·수정·삭제, 상태·기한 | Flask/SQLite | 구현 (사용자 로컬 동작 확인) |
| F-03 | 체크리스트 추가·수정·삭제·완료 토글·진행률 | Flask/SQLite | 구현 (사용자 수동 검증 6개 항목 통과) |
| F-04 | 공지 텍스트 분석·구조화 미리보기 | Gemini API | 구현 (실제 API 검증 대기) |
| F-05 | AI 분석 결과 확인·수정·저장 | Flask/SQLite | 구현 (로컬 검증 대기) |
| F-06 | 제출기한 달력 | JS/Flask | 미구현 |

F-02는 필수 과제명, 선택 과목·기한·설명·상태를 다룬다.
AI는 비정형 자연어 이해에만 사용하고 DB 저장·조회는 일반 코드로 처리한다.
날짜 불명확 시 추측하지 않고 확인 요청. 사용자 확인 후 저장.
현재 사용자 로그인/데이터 분리 미구현. 외부 공개 배포 전 인증과 보안 강화 필요.
