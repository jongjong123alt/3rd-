날짜 불명확 시 추측하지 않고 확인 요청. 사용자 확인 후 저장.
로그인 및 데이터 분리를 추가했으나 외부 공개 배포 전 추가 보안 검증이 필요.

## F-08~F-12 구현 참고
- F-08: 미완료 과제만 D-day를 표시하며 지난 기한은 D+N으로 표기.
- F-09: 기존 SQLite DB에는 priority 컬럼을 안전하게 추가하고 기존 과제는 '보통'으로 설정.
- F-10: JSON은 과제·체크리스트·메모·AI 일정을 포함하는 백업 파일이며 F-16에서 복원 기능을 추가함. CSV는 과제 목록만 포함하며 Excel 수식 주입을 방지함.
- F-11: 과제별 메모/진행 기록을 시간순으로 저장하고 과제 삭제 시 함께 삭제.
- F-12: 진행 상태, 과목별 분포(상위 5개), 전체 체크리스트 진행률 표시.
- 로그인·계정 분리(F-18)를 추가함. 백업 내보내기/복원은 로컬 PC에서만 허용하며 현재 계정 데이터만 처리함. 공개 배포 전 추가 보안 검증 필요.

## 로그인 전 공개 미리보기 (추가 개선)
- 비로그인 방문자는 서비스 소개, 전체 21개 기능 목록, 9개 유형의 예시 화면을 조회할 수 있다.
- 공개 미리보기는 고정 샘플 데이터만 사용하고 개인 과제 DB는 읽지 않는다.
- 과제 등록·조회·수정·삭제, AI 분석·일정 생성, 첨부파일, 백업 등 실제 데이터 접근은 로그인해야 한다.
- 실제 AI 호출·과제 저장 POST는 로그인하지 않은 사용자에게 401을 반환한다.
- 로컬 회원가입 제한과 계정별 데이터 분리는 기존 동작을 유지한다.
